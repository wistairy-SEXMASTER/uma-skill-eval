      計算方法・注意事項
      

        
    
          
  • 評価点は skill_data.grade_value、SPは single_mode_skill_need_point.need_skill_point の値です。
    • 
          
  • 上昇評価点は「このスキルの評価点 − 直下の下位スキルの評価点」、上昇効率は「上昇評価点 ÷ このスキルのSP」です。すでに下位スキルを取得している場合の効率です。
    • 
          
  • 下位込みSPは、上位スキル取得に必要な下位スキル（同じ group_id の下位 group_rate）のSPを合計した値です。総合効率は「評価点 ÷ 下位込みSP」です。
    • 
          
  • 同じグループのスキルを複数選択した場合、最も上位（group_rate が最大）の1つだけを合計に加算します。下位スキルは「集計外」と表示されます。
    • 
          
  • 上位スキルを選択すると、同じグループの下位スキルも自動的に選択されます。例: 「決意の直滑降」を選ぶと「直滑降」も選択されます。下位スキルは「集計外」と表示され、合計には上位スキルのみが加算されます。進化スキルを選択した場合も、進化元の金スキル本体とその下位スキルが自動的に選択されます。
    • 
          
  • 固有・進化はSPでは取得できませんが、評価点は合計に加算されます（合計SPには含まれません）。
    • 
          
  • マイナス系（group_rate = -1 または評価点が負）は初期状態では非表示です。必要に応じて「マイナス系を含む」をオンにしてください。
    • 
          
  • ヒントLvはスキルごとに、一覧の「ヒントLv」列で変更できます。初期値は全スキルLv0（割引なし）です。「ヒントLvリセット」で全スキルのヒントLvを0に戻せます。「ヒントLv」列のヘッダー、または「並び順」からヒントLv順にソートできます。
    • 
          
  • ヒントLvによるSP減少率は Lv1 −10% / Lv2 −20% / Lv3 −30% / Lv4 −35% / Lv5 −40% です。割引後のSPはスキルごとに小数点以下切り捨てで計算します（例: 170SPのLv4 → 110SP）。
    • 
          
  • 切れ者をオンにすると、ヒントLvの割引に −10% を加算します（例: Lv5＋切れ者 = −50%）。切れ者は全スキルに適用されます。
    • 
          
  • 上位スキルの「下位込みSP」は、下位スキルそれぞれに設定したヒントLvで割引したSPを合計します。下位スキルのヒントLvを変えると、上位スキルの下位込みSPにも反映されます。
    • 
          
  • 適性倍率は「査定設定」の距離適性・脚質適性から適用します。S/A = ×1.1、B/C = ×0.9、D/E/F = ×0.8、G = ×0.7 です。芝・ダートは倍率に影響しません。
    • 
          
  • スキル説明の ＜中距離/長距離＞ のように / で区切られた条件は良い方の適性を使い、＜先行・中距離＞ のように ・ で区切られた条件は両方の倍率を乗算します。初期値はすべてAです。
    • 
          
  • 固有スキルは「固有Lv × 170」で計算し、適性倍率は適用しません（固有Lvは「査定設定」で1〜6）。ゲームデータを取得すると、取得済み固有スキルのLvが自動で反映されます。継承固有は一律180です。
    • 
          
  • 進化スキルは通常スキルと同じく適性倍率を適用します。
    • 
          
  • ウマ娘を選ぶと、そのカードの距離適性・脚質適性を「査定設定」に自動反映します。芝・ダート適性は表示のみで、評価点倍率には影響しません。「適性リセット」で選択中のウマ娘の初期適性に再設定できます（未選択時は距離・脚質をすべてAに戻します）。
    • 
          
  • ゲームデータを取得すると、カードの初期スキル（ヒントLv0）とヒントを取得したスキルを自動で選択します。初期スキルは覚醒Lvに応じて3〜7件で、現在の覚醒Lv（talent_level）以下の必要覚醒Lvのものだけを選びます。ゲーム内で購入できるのはこの2種類で、すべてのノーマル/レアが最初から買えるわけではありません。取得済みスキルは選択から外します。継承固有は親から継承したものだけが取得可能で、パケットから継承元を判別できないため自動選択の対象外です（必要なら手動でチェックしてください）。
    • 
          
  • 適性フィルタは距離・馬場・脚質のチップで絞り込みます。スキルの適性条件のうちいずれか1つでも一致すれば表示します（例: ＜短距離・芝＞ は短距離または芝のどちらかで表示）。「汎用を含む」をオフにすると、適性条件のないスキルを除外します。
    • 
          
  • 効果カテゴリは「速度」「加速」「回復」「緑」「デバフ」「位置取り」「視野」「ゲート」などのチップで絞り込みます。主効果（ability_type_1_1）で分類し、複数効果があるスキルは最初の効果を使います。
    • 
          
  • ウマ娘を選ぶと、そのカードが最初から持っている金スキルと、その進化先スキルを表示します。各金スキルごとのドロップダウンで「通常」または「進化先」を選択できます。固有スキルは進化の対象外です。進化スキルのSPは進化元の金スキルのヒントLv・SPを使用します。
    • 
          
  • シナリオ進化では、選択したシナリオで選択可能な進化スキルを一覧表示します。「選択」でその進化スキルを選択でき、進化元の金スキルと他の進化先は自動的に外れます。選択済みの場合は「解除」で選択を解除できます。
    • 
          
  • 獲得SPから最大評価を計算は、入力したSP予算内で合計評価点が最大になるスキルの組み合わせを求めます。ゲームデータを取得すると、現在の残SPが「獲得SP」に自動で反映されます。同じグループは最上位1つを選び、下位スキルのSPもコストに含めます。ヒントLv・切れ者・適性倍率を反映します。固有・継承固有などSP対象外のスキルは計算対象外です。合計評価点が同じ組み合わせが複数ある場合は、上昇効率（（このスキルの評価点 − 直下の下位スキルの評価点）÷ このスキルのSP）の合計が高いものを優先し、結果はヒントLvの高い順（同じLv内は上昇効率の高い順）に表示します。選択中のスキルがある場合は、その選択だけを対象に計算します。進化先は進化元に対する増分が最大のものを選びます。シナリオ進化は最大2個まで考慮します。
    • 
          
  • 計算モード「技能試験スコア」では、トレーナー技能試験（フリー課程）の追加スコアが最大になる組み合わせを求めます。スコア = 評価点 + スキル獲得ボーナス（ノーマル+400 / レア+1,200 / 進化+1,500、継承固有はノーマル、継承進化は進化扱い）。系統ごとに最上位1個のボーナスだけを加算し、取得済みの下位スキル分は増分で計算します。基礎能力ボーナス・勝利レースボーナスは含みません。進化スキルは進化元のSPをコストとして扱い、現在のカード・シナリオ・継承で使える進化先を候補に加えます。進化先が複数ある場合は進化元に対する増分が最大のものを選びます。シナリオ進化は最大2個まで考慮します。
    • 
          
  • 「結果を選択に反映」を押すと、計算結果のSP取得スキルを選択状態にします（SP対象外の選択は保持）。
    • 
          
  • 画像認識は「画像を追加」またはドラッグ＆ドロップ、クリップボード貼り付け、画面キャプチャに対応しています。画像はブラウザ内で処理され、外部に送信されません（OCRエンジンの取得のみネット接続を使用）。
    • 
          
  • 画面キャプチャはChrome/Edgeで開いた場合に利用できます。OpenCode内蔵ブラウザでは権限が拒否されるため、「画像を追加」または「クリップボードから貼り付け」を使ってください。
    • 
          
  • 「変化時取り込み」はスクロールのフレーム変化を検出し、スクロールが止まった画面を自動保存します（最大120枚）。100件規模のヒントも画面を分けて取り込めます。
    • 
          
  • 変化時取り込みは画面全体とスキル一覧領域の両方を比較します。感度（高/中/低）で調整でき、取り込み中は「画面 diff / 一覧 diff / 取り込み枚数」を表示します。ゲーム画面は共有画面の左側に置いてください。
    • 
          
  • 高速モード（初期オン）はOCRを1パス・1400px・2並列で処理します。精度を優先する場合はオフにしてください。
    • 
          
  • ゲーム内フォント（UMAMUSUME-RodinWanpaku）を抽出して候補名の画像照合に使用します。○ / ◎ / × の区別やOCRの文字誤りを補正します。フォントが無い場合は通常のOCRのみ動作します。
    • 
          
  • スキル取得画面モードでは、スキル名とヒントLvを認識します。SPコストはOCRしません。スキル一覧を自動クロップし、オレンジのヒントバッジからLvを読み取ります。
    • 
          
  • ウマ娘の適性モードでは、キャラ名・衣装名を認識し、カードの初期適性を設定します。候補が複数ある場合は選択できます。
    • 
          
  • OCRは固定座標を使わず、画像全体を正規化して認識するため、ウィンドウサイズが変わっても動作します。初回は日本語OCRデータのダウンロードで時間がかかります。
    • 
          
  • 認識結果は誤ることがあります。結果表のヒントLvを確認・修正してから「反映」してください。
    • 
          
  • 特殊スキル（ストーリー・イベント用）と期限切れスキルは収録していません。データは extract_skills.py で再生成できます。
