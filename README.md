# ウマ娘 スキル評価点 査定

`master.mdb` から **スキル名・評価点・スキルポイント(SP)** を抽出し、査定用の一覧表示と合計計算を行うツールです。

`index.html` をブラウザで開くだけで使えます（ローカルファイルのまま動作します）。

## できること

- スキル名・説明・スキルIDでの検索（スペース区切りでAND）
- 種別（ノーマル／レア／固有／継承固有／進化）で絞り込み
- カテゴリ（コース・馬場・天候／スタート・序盤／中盤／終盤／コーナー・直線／固有）で絞り込み
- SP取得可能なスキルのみ表示
- マイナス系スキルの表示切り替え（初期状態は非表示）
- 選択中スキルのみ表示
- 評価点・SP・上昇評価点・上昇効率・下位込みSP・総合効率でソート
- 行クリックでスキルを選択し、合計評価点・合計SP・総合効率をリアルタイム計算
- 同じグループのスキルは、最も上位の1つだけを合計に加算
- 選択したスキルをCSV出力（Excel向け UTF-8 BOM）
- ヒントLv（0〜5）をスキルごとに設定し、割引後SP・効率を再計算
- 切れ者の有無を設定し、ヒントLvのSP割引に −10% を加算
- 距離適性・脚質適性（S〜G）を設定し、スキル評価点に適性倍率を適用
- 固有レベル（1〜6）を設定し、固有スキルを「Lv × 170」で計算
- 選択状態・ヒントLv・査定設定をブラウザの `localStorage` に保存

## 使い方

1. `C:\Users\wister2\apps\uma-skill-eval\index.html` をブラウザで開く
2. 検索欄やフィルタでスキルを絞り込む
3. 行をクリックしてスキルを選択する
4. 必要に応じて「査定設定」で、切れ者・固有Lv・距離適性・脚質適性を設定する
5. 必要に応じて一覧の「ヒントLv」列で、スキルごとのヒントLvを変更する
6. 画面下部に合計評価点・合計SP・総合効率が表示される
7. 必要に応じて「CSV出力」を押す

> `data/skills.js` を相対パスで読み込むため、`index.html` をダブルクリックして開いても動作します。

## 列の意味

以下は `out/*.csv`（抽出データ）の列です。ビューアのCSV出力はヒント割引前後の列を分けて出力します（「ヒントLv」を参照）。

| 列 | 内容 |
| --- | --- |
| `skill_id` | `skill_data.id` |
| `name` | スキル名（`text_data.category = 47`） |
| `type` | ノーマル／レア／固有／継承固有／進化／特殊 |
| `rarity` | `skill_data.rarity`（1=ノーマル、2=レア、3〜5=固有、6=進化） |
| `eval_point` | 評価点。`skill_data.grade_value` |
| `sp` | そのスキル単体のSP。`single_mode_skill_need_point.need_skill_point` |
| `upgrade_point` | 下位スキルからの上昇評価点（`eval_point - prereq_eval`） |
| `efficiency` | 上昇効率（`upgrade_point / sp`）。下位取得済み前提 |
| `total_sp` | 下位スキル取得込みのSP（`sp + prereq_sp`） |
| `total_efficiency` | 総合効率（`eval_point / total_sp`） |
| `group_id` | スキルのグループID。同じグループは上位スキルで置き換わる |
| `group_rate` | 1=基本、2=上位、3=最上位、-1=マイナス系 |
| `prereq_sp` | 下位スキル取得に必要なSPの合計 |
| `prereq_eval` | 下位スキルのうち評価点が最大のもの |
| `category` | スキルカテゴリ（下記） |
| `category_label` | カテゴリの表示名 |
| `purchasable` | SPで取得可能か（`sp` が存在するか） |
| `available` | 期間限定スキルが現在有効か |
| `description` | 説明文（`text_data.category = 48`） |
| `start_date` / `end_date` | 期間限定スキルの開始・終了（Unixタイムスタンプ） |
| `apt_distance` | 距離適性の条件（`1`=短距離、`2`=マイル、`3`=中距離、`4`=長距離。`/` はOR） |
| `apt_style` | 脚質適性の条件（`1`=逃げ、`2`=先行、`3`=差し、`4`=追込。`/` はOR） |
| `apt_source` | 適性条件の取得元（`tag`=説明文の＜＞、`condition`=発動条件、空=適性条件なし） |

### ヒントLv

ヒントLvによるSP減少率は次のとおりです。ゲーム内と同様に、割引後のSPは**小数点以下切り捨て**で計算します。

| ヒントLv | 減少率 | 170SPの例 |
| --- | ---: | ---: |
| Lv0 | 0% | 170 |
| Lv1 | 10% | 153 |
| Lv2 | 20% | 136 |
| Lv3 | 30% | 119 |
| Lv4 | 35% | 110 |
| Lv5 | 40% | 102 |

- 一覧の「ヒントLv」列で、スキルごとにLvを設定します（初期値はLv0）。
- 設定はスキルIDごとに `localStorage` へ保存され、次回開いたときも復元されます。
- 上位スキルの「下位込みSP」は、下位スキルそれぞれに設定したヒントLvで割引したSPを合計します。下位スキルのヒントLvを変えると、上位スキルの下位込みSPにも反映されます。

CSV出力では、ヒント割引前と割引後の両方を出力します。

| 列 | 内容 |
| --- | --- |
| `sp_base` / `sp` | そのスキル単体のSP（割引前 / 割引後） |
| `hint_level` | 適用したヒントLv |
| `total_sp_base` / `total_sp` | 下位込みSP（割引前 / 割引後） |
| `prereq_sp_base` / `prereq_sp` | 下位スキル分のSP（割引前 / 割引後） |
| `efficiency` | 上昇効率（割引後SPで計算） |
| `total_efficiency` | 総合効率（割引後SPで計算） |

### 切れ者

- 「査定設定」の「切れ者」をオンにすると、ヒントLvの減少率に **−10%** を加算します。
- 例: Lv5（−40%）＋切れ者 = **−50%**、Lv0＋切れ者 = **−10%**。
- 割引後SPはヒントLvと同じく小数点以下切り捨てです。
- 切れ者は選択中の全スキルに適用されます。

### 適性倍率

| 適性 | 倍率 |
| --- | ---: |
| S / A | 1.1 |
| B / C | 0.9 |
| D / E / F | 0.8 |
| G | 0.7 |

- 「査定設定」の距離適性（短距離・マイル・中距離・長距離）と脚質適性（逃げ・先行・差し・追込）を設定します。初期値はすべてAです。
- **芝・ダートは倍率に影響しません。** 距離適性と脚質適性だけが対象です。
- 説明文の ＜中距離/長距離＞ のように **`/`** で区切られた条件は、同じカテゴリのORです。**良い方の適性**を使用します。
- ＜先行・中距離＞ のように **`・`** で区切られた条件は、異なるカテゴリのANDです。**両方の倍率を乗算**します。
- 例: 先行A・中距離A → 1.1 × 1.1 = **1.21倍**。先行G・中距離G → 0.7 × 0.7 = **0.49倍**。
- 倍率適用後の評価点は四捨五入します（uma-tools と同じ単精度積算）。
- 固有・継承固有スキルは適性倍率の対象外です。

### 固有レベル

- 「査定設定」の固有Lv（1〜6）は、種別が「固有」のスキルに適用します。
- 固有スキルの評価点 = **固有Lv × 170**（Lv1=170、Lv6=1,020）。適性倍率は適用しません。
- **継承固有**スキルは一律 **180** です。
- **進化**スキルは通常スキルと同じく、評価点に適性倍率を適用します。

### カテゴリ

| 値 | ラベル |
| --- | --- |
| 0 | コース・馬場・天候 |
| 1 | スタート・序盤 |
| 2 | 中盤 |
| 3 | 終盤 |
| 4 | コーナー・直線 |
| 5 | 固有 |
| 101 | イベント |

## 計算式

```text
適性倍率（通常・進化） = 距離倍率 × 脚質倍率（該当する条件のみ）
評価点（通常・進化）   = round(grade_value × 適性倍率)
評価点（固有）         = 固有Lv × 170
評価点（継承固有）     = 180
上昇評価点 = 評価点 - 下位スキルの評価点（同じ査定設定で計算）
上昇効率   = 上昇評価点 / そのスキル単体のSP（ヒント割引後）
下位込みSP = そのスキル単体のSP + 下位スキルのSP合計（各スキルのヒントLvで割引）
総合効率   = 評価点 / 下位込みSP

割引後SP = floor(割引前SP × (1 - ヒントLvの減少率 - 切れ者10%))
```

### グループの扱い

同じ `group_id` のスキルは下位→上位の関係です。たとえば `右回り○` → `右回り◎` → `右回りの鬼` は同じグループです。

- ビューアで同じグループの複数スキルを選択した場合、`group_rate` が最も大きい1つだけを合計に加算します。
- 下位スキルは「集計外」と表示されます。
- 上位スキルを選択すると、その `total_sp`（下位込みSP）が合計SPに加算されます。
- 下位スキルだけを選択した場合は、そのスキル単体のSPが加算されます。

## 注意事項

- 評価点は基本値 `skill_data.grade_value` に、設定した**適性倍率**を適用して計算します（S/A=1.1、B/C=0.9、D/E/F=0.8、G=0.7）。
- 固有スキルは**固有Lv × 170**で計算します（継承固有は一律180）。固有Lvは「査定設定」で1〜6を指定してください。
- ヒントLvによるSP割引（Lv1 −10% 〜 Lv5 −40%、小数点以下切り捨て）と、**切れ者 −10%** を実装済みです。
- 固有・進化スキルはSPでは取得できませんが、ビューアでは評価点だけを合計に加算します（「SP対象外の評価点」として表示）。
- マイナス系スキル（`group_rate = -1` または評価点が負）は初期状態では非表示です。「マイナス系を含む」をオンにすると表示されます。
- 特殊スキル（ストーリー・イベント用）と期限切れスキルは `data/skills.js` には収録していません。
- ゲームのアップデートで評価点・SPが変わった場合は、`py extract_skills.py` を再実行してデータを更新してください。
- 本ツールはゲーム内の査定値を完全に再現するものではありません。スキル選択の比較・目安として使用してください。

```powershell
py verify.py
```
